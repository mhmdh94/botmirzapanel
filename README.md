# botmirzapanel — فورک سفارشی (mhmdh94)

ربات فروشگاهی VPN مبتنی بر میرزا، با پنل **PasarGuard / مرزبان** و امکانات اضافه‌شده در این فورک.

> آخرین وضعیت کد محلی این بسته با تغییرات تست‌شده روی سرور هم‌خوان است.  
> تاریخ مستندسازی: 2026-10-17

---

## نصب / آپدیت

```bash
# نصب (اسکریپت داخل ریپو)
bash <(curl -sSL https://raw.githubusercontent.com/mhmdh94/botmirzapanel/main/install.sh)
```

آپدیت دستی پیشنهادی:
1. از پوشه ربات بک‌آپ بگیرید (`config.php`، دیتابیس، تصاویر).
2. فقط فایل‌های PHP زیر را جایگزین کنید؛ **`config.php` را دست نزنید**.
3. کرون هوشمند را در crontab داشته باشید (نمونه پایین).

### فایل‌های اصلی که معمولاً آپدیت می‌شوند

| فایل | نقش |
|------|-----|
| `index.php` | ورودی کاربر، خرید، سرویس‌ها، ریسلر |
| `admin.php` | پنل ادمین، تأیید رسید، تنظیمات |
| `functions.php` | هسته پرداخت، کرون، گزارش، ریسلر، پورسانت |
| `text.php` | متن‌های ربات |
| `keyboard.php` | کیبورد کاربر/ادمین |
| `pasarguard.php` | API پنل پاسارگارد + حجم ادمین ریسلر |
| `reseller_volume.php` | **جدید** — خرید حجم پنل نمایندگی (جدا از فروش اکانت) |
| `cron/croncard.php` | تأیید خودکار رسید |
| `cron/smart_cron.php` | کرون هوشمند (اخطار/حذف فاکتور غایب/ریسلر) |
| `table.php` | ساخت/مهاجرت جداول |

## امکانات مهم این فورک

### فروش و پرداخت
- حداقل/حداکثر واریزی قابل تنظیم از بخش مالی
- پکیج‌های شارژ با تخفیف
- پرداخت کریپتو (نرخ از والکس) + کارت‌به‌کارت
- قفل اتمیک رسید (`waiting` → `paid`) تا شارژ دوبل نشود
- بعد از تأیید: ساخت سرویس / شارژ کیف + پیام قطعی به کاربر (بدون پیام تکراری)
- در خطای ساخت سرویس: برگشت وجه در صورت کسر
- تلاش مجدد برای خطای پنل (مثلاً panel not found)

### سرویس‌های من و خرید
- جستجوی سرویس، فعال/غیرفعال، تمدید، حجم اضافه (قابل خاموش از قابلیت‌ها)
- نام کاربری دلخواه + «خودکار انتخاب کن»
- لینک اشتراک با راهنمای Happ
- آمار فروش/واریزی (امروز، دیروز، هفته، ماه) از فاکتورهای دیتابیس

### کرون هوشمند (`cron/smart_cron.php`)
- اخطار حجم / زمان / اتمام سرویس (قابل خاموش‌روشن از ربات)
- تمدید اضطراری یک‌بارمصرف (اختیاری)
- حذف **فقط فاکتور** از دیتابیس ربات وقتی پنل صریحاً User not found بدهد (کاربر را از پنل پاک **نمی‌کند**)
- هشدار حجم پنل ریسلر (اگر قابلیت ریسلر روشن باشد)
- دیباگ اختیاری برای کانال گزارش

نمونه crontab (مسیر را عوض کنید):

```cron
*/5 * * * * php /var/www/html/YOURBOT/cron/smart_cron.php >/dev/null 2>&1
*/3 * * * * php /var/www/html/YOURBOT/cron/croncard.php >/dev/null 2>&1
```

> اگر فقط smart استفاده می‌کنید، کرون‌های قدیمی `cronday` / `cronvolume` / `removeexpire` را غیرفعال کنید مگر نیاز خاص داشته باشید.  
> `removeexpire` می‌تواند یوزر را از **پنل** هم حذف کند.

### مشارکت در فروش (پورسانت)
- پنل یکپارچه تنظیمات در ادمین
- پورسانت بعد از خرید موفق
- لیست **کاربران فعال در طرح** (پورسانت‌گرفته‌ها)
- واریز امن‌تر به کیف معرف

### پنل نمایندگان (Reseller) — کاملاً جدا از فروش اکانت
- فایل: `reseller_volume.php` + جداول `reseller_panel_cfg` / `reseller_volume_plan` / ...
- قابلیت پیش‌فرض **خاموش** (`status_reseller_panel`)
- دکمه کاربر: «پنل نمایندگی» | ادمین: «مدیریت پنل نمایندگان»
- خرید حجم برای ادمین پنل با موجودی یا فاکتور کمبود
- حجم در پنل **به قبلی اضافه** می‌شود (نه ریست کامل)
- هشدار مصرف در آستانه‌های قابل تنظیم؛ بعد از افزایش حجم (ربات یا دستی در پنل) دوباره فعال می‌شود

### کانال گزارش
- انواع رویداد قابل خاموش/روشن (خرید، تمدید، رسید، مسدود، ریسلر، …)
- یک پیام به ازای هر هشدار ریسلر (بدون دیباگ تکراری)

### امنیت و ضد اسپم
- مسدود خودکار اسپم با پیام محدود به پشتیبانی
- استثنای ادمین
- گزارش مسدود دستی/خودکار به کانال

### قابلیت‌های قابل خاموش‌روشن
عضویت اجباری کانال، موجودی در منو، اکانت تست، خرید جدید، جستجو، مشارکت، تعرفه، حجم اضافه، افزایش موجودی، پشتیبانی، تمدید، ریسلر و …

## جداول / تنظیمات اضافه‌شده (نمونه)

ربات در اجرا با `ensure*` می‌سازد؛ نیازی به SQL دستی نیست مگر خطای خاص:

- `PaySetting` — فلگ‌های smart، گزارش کانال، حداقل واریز، …
- `smart_cron_state` — وضعیت اخطار هر سرویس
- `reseller_panel_cfg`, `reseller_volume_plan`, `reseller_volume_order`
- `reseller_admin_warn_state` — سطح هشدار حجم ادمین پنل
- ستون‌های کاربر: `affiliates_balance`, `panel_admin_*` و …

## نکات مهم قبل از آپلود روی سرور

1. **همیشه بک‌آپ** از `config.php` و دیتابیس بگیرید.
2. `config.php` و پوشه `vendor` را از گیت جایگزین نکنید مگر عمدی.
3. بعد از آپلود یک‌بار ربات را `/start` کنید تا کیبورد تازه بیاید.
4. قابلیت ریسلر را فقط وقتی پنل ریسلر را تنظیم کردید روشن کنید.
5. مسیر کرون را با نام واقعی پوشه ربات چک کنید تا کرون ربات دیگر پاک/اجرا نشود.
